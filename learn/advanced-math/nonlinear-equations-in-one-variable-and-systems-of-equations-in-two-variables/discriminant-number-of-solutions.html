The Discriminant: How Many Solutions?

One number — D = b² − 4ac — tells you whether a parabola crosses the x-axis twice, kisses it once, or never touches it at all.

The discriminant of a quadratic equation ax² + bx + c = 0 is D = b² − 4ac — the number under the square root in the quadratic formula. Its sign counts the real solutions: D > 0 gives two, D = 0 gives exactly one (the parabola is tangent to the x-axis), and D < 0 gives none. In this interactive lesson you slide a live parabola through all three cases, then use D to crack the SAT's favorite 'for what value of k' question.

Key takeaways

  • Roots are x-intercepts: The real solutions of ax² + bx + c = 0 are exactly the x-values where the parabola y = ax² + bx + c meets the x-axis. Counting solutions = counting touches.
  • The fork in the formula: x = (−b ± √D) ⁄ 2a with D = b² − 4ac — the discriminant lives under the square root. The ± can only fork into two different answers when D is positive. Exam tip: Watch the signs: when a and c have opposite signs, −4ac is positive. Most discriminant errors are sign slips inside −4ac.
  • Three cases, one sign: D > 0: two crossings, two real solutions. D = 0: tangent — one repeated solution at x = −b ⁄ 2a. D negative: the parabola floats — no real solutions. Exam tip: On the SAT, a 'how many solutions' question never needs the actual roots — compute the sign of D and answer.
  • Solve for k like a pro: When a question fixes the NUMBER of solutions and asks for a parameter, translate the count into a condition on D, then solve. 'Exactly one solution' for x² + 6x + k = 0 means 36 − 4k = 0, so k = 9. Exam tip: Solving for a parameter k from a solution-count condition is a classic SAT-Hard move: two solutions ⇒ D > 0, exactly one ⇒ D = 0, none ⇒ D negative — write the equation or inequality about D first, then solve for k.

Lesson transcript

  1. Here's a parabola: y = x² − 3. I want to ask it exactly one question — does it ever touch the x-axis? Maybe it crosses twice. Maybe it just barely kisses. Maybe it never gets there at all. And here's the wild part: that question has a NUMBER. One single number answers it, without solving anything. Let's go find it.
  2. First, what does 'touch the x-axis' even mean? On the x-axis, y is zero. So the touching points are exactly the x-values where x² − 3 = 0 — the SOLUTIONS of the equation. Look: this parabola crosses at x ≈ −1.73 and x ≈ 1.73 — that's ±√3. Roots, x-intercepts, solutions: three names for the same dots.
  3. Now meet the number. The quadratic formula says x = (−b ± √D) ⁄ 2a, where D = b² − 4ac — the DISCRIMINANT, the part living under the square root. For our curve: D = 0² − 4(1)(−3) = 12. Positive. And here's the key: the ± can only split into two different answers when D is positive — √12 ≈ 3.46, so x = ±3.46⁄2 = ±1.73, the two dots you just saw. The whole question of HOW MANY solutions hides inside the sign of D.
  4. Let's make the picture more interesting — shift the parabola by setting b to −2: y = x² − 2x − 3. Recompute: D = (−2)² − 4(1)(−3) = 4 + 12 = 16. Still positive, so still two crossings — there they are, at x = −1 and x = 3. From now on the readout card computes D live, straight from the graph. Watch it like a heartbeat.
  5. Time for the experiment. I'll slide c upward — the whole parabola rises with it. With a = 1 and b = −2, the readout is D = 4 − 4c, so every notch c climbs, D drops. And watch the two roots: they are walking toward each other. At c = 0, D = 4 — the roots are already close. At c = 0.9, D = 0.4 — they are almost touching. Something special is about to happen.
  6. There. At exactly c = 1, the two roots merge into a single point: the parabola is TANGENT to the x-axis — one gentle kiss at x = 1. Check the number: D = (−2)² − 4(1)(1) = 4 − 4 = 0. The square root of zero is zero, so the ± splits into... nothing. x = −b ⁄ 2a = 1, once. One repeated solution — mathematicians call it a double root.
  7. Push c past 1 and the kiss is over. At c = 3 the parabola floats completely above the axis — it never touches, so x² − 2x + 3 = 0 has NO real solutions. The number agrees: D = 4 − 12 = −8, negative — and you cannot take a real square root of a negative. That's the whole trichotomy: D positive, two. D zero, one. D negative, none.
  8. Your turn. Grab the parabola — or use the slider — and move c until the curve JUST kisses the x-axis. Keep one eye on the D readout while you drag: you are hunting for the exact spot where it hits zero.
  9. Now the SAT move. A classic hard question reads: 'For what value of k does x² + 6x + k = 0 have exactly one solution?' Don't solve — TRANSLATE. Exactly one solution means D = 0. Write it: D = 6² − 4(1)(k) = 36 − 4k. Set it to zero: 36 − 4k = 0, so k = 9. And watch the graph confirm it — as c rises to 9, the parabola comes up and kisses the axis at x = −6 ⁄ 2 = −3. Exactly one solution. Turning words about counting into an equation about D — that is the entire trick.
  10. Final challenge — this time YOU are the discriminant. Three targets: give the equation two solutions, then exactly one — the tangent kiss — then none at all. Drag c and release when the readout matches the target.
  11. Keep this one picture: a parabola sliding up, two roots walking toward each other, merging at the kiss, then gone. One number narrated the whole story — D = b² − 4ac. Positive: two solutions. Zero: one, tangent. Negative: none. And when the SAT asks 'for what value of k', you answer with an equation about D. Frequently asked questions

What is the discriminant of a quadratic equation?

The discriminant is D = b² − 4ac, computed from the coefficients of ax² + bx + c = 0. It is the expression under the square root in the quadratic formula, and its sign tells you how many real solutions the equation has.

How many real solutions are there when the discriminant is zero?

Exactly one — a repeated (double) root at x = −b ⁄ 2a. On the graph, the parabola is tangent to the x-axis: it touches at a single point without crossing.

What does a negative discriminant mean?

No real solutions. The parabola never touches the x-axis — it floats entirely above or below it. The two solutions become complex numbers, which the SAT only ever asks about as 'no real solutions'.

For what value of k does x² + 6x + k = 0 have exactly one solution?

Translate 'exactly one solution' into D = 0. Here D = 6² − 4(1)(k) = 36 − 4k, so 36 − 4k = 0 and k = 9. This translate-then-solve move is the classic SAT-Hard pattern.

Do I have to solve the quadratic to count its solutions?

No. Computing D = b² − 4ac is enough: D > 0 means two real solutions, D = 0 means one, D < 0 means none. Counting solutions never requires finding the actual roots.

Why does the discriminant control the number of solutions?

Because it sits under the square root in x = (−b ± √D) ⁄ 2a. If D > 0 the ± produces two different answers; if D = 0 the square root vanishes and both answers coincide; if D < 0 the square root is not a real number at all.
